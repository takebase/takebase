# @takebase/sdk

The Takebase browser client: tenant discovery and selection, typed collection CRUD and realtime subscriptions. It depends only on `@takebase/contracts`.

> Not on a registry yet. The package is `private: true` at version 0.0.0, and it has no license yet. See [Installing](../../README.md#installing) in the root README.

The SDK is never a security boundary. Every request is decided again by the collection rules on the server.

## Use it

```ts
import { firebaseConnector } from "@takebase/adapter-firebase/client";
import { createClient } from "@takebase/sdk";
import { initializeApp } from "firebase/app";
import { getAuth } from "firebase/auth";

type Note = { title: string; done: boolean };

const app = initializeApp({ apiKey: "<web api key>", projectId: "<firebase project>" });
const client = createClient({
	globalUrl: "<global worker url>",
	auth: getAuth(app),
	realtime: { connector: firebaseConnector(app) },
});

// After a Firebase sign-in:
const [membership] = await client.auth.getTenants();
await client.useTenant(membership.tenant.id);

const notes = client.collection<Note>("notes");
await notes.create({ title: "First", done: false });
const { items } = await notes.getList({ sort: "-created" });

// A signal only says something changed: refetch through the API, where the rules apply.
const unsubscribe = notes.subscribe("*", async () => {
	const { items } = await notes.getList({ sort: "-created" });
	console.log(items);
});
```

Sign out or a revoked membership signs the user out fully and wipes local state; `client.auth.onSignedOut` tells you when. `app/src` in a project generated by `takebase create` is a complete example.

## Limits

Tested in Chromium only, with Firebase JS SDK 13.0.0, through the local emulators and the approved staging environment.
