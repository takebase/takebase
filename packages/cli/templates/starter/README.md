# {{name}}

A Takebase starter: a Hono app on Cloudflare Workers with a local D1 database,
generated by `takebase init` / `takebase create`.

```sh
pnpm install
pnpm dev         # http://localhost:8787/health
pnpm typecheck   # generates worker-configuration.d.ts, then runs tsc
```

Everything runs locally; no Cloudflare account is needed until you deploy.
Before `pnpm deploy`, create a D1 database with `wrangler d1 create {{name}}` and put
its id in `wrangler.jsonc`.

Keep secrets out of the repository: use `.dev.vars` locally (git-ignored) and
`wrangler secret put` for deployed Workers. The starter ships no credentials.
